# Blackglass cinematic assets

The reconstruction renderer expects real binary JPEG assets in this directory. These files must be committed through Git blob objects, not text-file helpers.

- `canonical-cast-atlas.jpg`: seven locked character identities.
- `room-atlas.jpg`: nine photographic room plates.
- `weapon-atlas.jpg`: six photographic method props.
- `ruby-victim-base.jpg`: locked Ruby victim source plate.
- `board-master.jpg`: hotel board master artwork.
