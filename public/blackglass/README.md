# Blackglass cinematic assets

The reconstruction system builds the complete Blackglass scenario-card library at runtime instead of storing 1,620 near-duplicate JPEGs. The game catalog is organized in nine room batches of 180 cards each:

`9 rooms × 6 killers × 5 different victims × 6 weapons = 1,620 scenario cards`

Every rendered card uses the same canonical source cells for character identity, room art and weapon art, then composes the requested killer, victim, room and weapon into the cinematic scene plus the four-part card strip.

Binary art assets in this directory must be committed through Git blob objects, not text-file helpers.

- `canonical-cast-atlas.jpg`: seven source cells. Cell zero retains the retired Mara Voss art for compatibility; the live six-person cast is Dex Vale, Dr. Imani Cross, Theo Rook, June Mercer, Elias Flint and Ruby Ash.
- `room-atlas.jpg`: nine photographic room plates.
- `weapon-atlas.jpg`: six photographic weapon/prop plates.
- `ruby-victim-base.jpg`: legacy/full-scene Ruby victim source retained for the Ruby victim variant.
- `board-master.jpg`: hotel board master artwork.

The live catalog and per-room batches are generated by `src/games/bloodalibi/scenarioCatalog.js`. The renderer deliberately uses a family-game treatment: the weapon and staging communicate the theory without graphic wounds or gore.
