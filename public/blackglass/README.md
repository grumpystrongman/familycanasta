# Blackglass cinematic assets

Blackglass supports the complete scenario-card matrix:

`9 rooms × 6 killers × 5 different victims × 6 weapons = 1,620 scenario cards`

The live catalog and per-room batches are generated by `src/games/bloodalibi/scenarioCatalog.js`: 180 cards per room across all nine rooms.

## Production card library

The game now has a production static-card pipeline in `scripts/blackglass/`. It creates individual upload-ready WebP cards under `public/blackglass/cards/<room>/` using deterministic filenames. When a generated card exists, the reconstruction modal uses that exact card. If a card has not been generated yet, the existing browser canvas reconstruction remains as a non-breaking fallback.

The image model generates only the large cinematic scene. Blackglass then composes the approved 1122×1402 design deterministically with Sharp: the black/gold frame, Killer/Victim/Location/Weapon tiles, canonical reference art, exact names and Blackglass branding. `card-template-reference.png` is the checked-in visual reference for that composition.

The factory is resumable and quality-gated. It starts with the economical configured image model, checks the scene with the configured small vision QA model, escalates failed scenes to the higher-fidelity image model, and refuses to publish a final card if the escalated scene still fails identity, room, weapon, visual-quality or family-game-safety thresholds.

See `public/blackglass/cards/README.md` for commands and output conventions.

## Canonical source assets

- `canonical-cast-atlas.jpg`: seven source cells. Cell zero retains the retired Mara Voss art for compatibility; the live six-person cast is Dex Vale, Dr. Imani Cross, Theo Rook, June Mercer, Elias Flint and Ruby Ash.
- `room-atlas.jpg`: nine room plates.
- `weapon-atlas.jpg`: six weapon/prop plates.
- `ruby-victim-base.jpg`: legacy Ruby victim source retained for compatibility.
- `board-master.jpg`: hotel board master artwork.
- `card-template-reference.png`: approved Blackglass scenario-card layout reference.

Binary art assets in this directory must be committed through Git blob objects rather than UTF-8 text-file helpers.

All generated scene prompts use a family-game treatment: the victim is fully clothed and apparently unconscious, the weapon is a separate evidence prop, and the scene forbids attack-in-progress, impact, wounds, blood, gore, bodily damage, sexual content, accidental text and watermarks.
