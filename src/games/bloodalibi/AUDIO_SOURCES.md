# Blackglass audio sources

Blackglass uses only audio explicitly released under Creative Commons Zero (CC0 1.0), so the tracks may be used in personal and commercial projects without royalties or required attribution. Credits are retained here for traceability.

## Background music

- **Moil** — Ruskerdax
- License: CC0 1.0 / public-domain dedication
- Original source: https://opengameart.org/content/moil
- Runtime mirror: a commit-pinned copy of `table-loop.mp3` from https://github.com/dinalUdagedara/poker
- Mood: slow dark jazz with Rhodes piano, jazz drums, baritone sax, and standup bass.

## Accusation zingers

- **Music Jingles — Saxophone** — Kenney
- License: CC0 1.0
- Original source: https://kenney.nl/assets/music-jingles
- Runtime mirror: commit-pinned `win.ogg` and `lose.ogg` copies from https://github.com/dinalUdagedara/poker
- The correct-accusation cue uses the win jingle; a false accusation uses the lose jingle.

The GitHub mirror's own `public/sounds/CREDITS.md` identifies `table-loop.mp3` as Ruskerdax's *Moil* (CC0) and the win/lose OGG files as Kenney Music Jingles released under CC0.
