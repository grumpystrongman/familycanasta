# Party Stage third-party audio

Party Stage intentionally uses recorded audio assets instead of generated browser tones or browser text-to-speech.

## Kenney — interface, impact, and voice audio

Source packs:
- UI Audio
- Interface Sounds
- Impact Sounds
- Voiceover Pack

Creator: Kenney / Kenney.nl
License: Creative Commons Zero (CC0 1.0 Universal)

The application loads these files from the public `lavenderdotpet/CC0-Public-Domain-Sounds` GitHub mirror. The mirror preserves the Kenney license files and pack credits. Kenney attribution is appreciated but not required under CC0.

Creator: Kevin MacLeod — incompetech.com
